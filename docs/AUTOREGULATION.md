> "Se ti fa male, non fare il workout. Se hai mangiato poco, riduci. Se sei stanco, recupera."
>
> Questo documento codifica le regole. L'app deve applicarle automaticamente.

## 🦵 Dolore davanti tibia (shin splints / stinco)

### Sintomi
- Dolore o fastidio davanti alla tibia (parte bassa o media)
- Compare durante o subito dopo cardio
- Spesso dopo aumento di volume/intensità

### Cause comuni
- Aumento troppo rapido di volume/velocità
- Scarpe inadeguate (poco ammortizzate)
- Atterraggio di tallone (heel-strike)
- Tapis rullante senza pendenza (impatto secco)
- Piedi piatti / sovrappronazione
- Cadenza troppo bassa (<150 ppm = passi lunghi e impattanti)
- **Carenza idrica/glicogeno** (muscolo posteriore tibia affatica per primo)

### Protocollo immediato (dolore acuto durante workout)

```
1. STOP immediato del workout corrente
2. 5 min cammino lento (4 km/h) per defaticare
3. Cool-down completo 3-5 min
4. Appena finito: ghiaccio sulla zona 15 min
5. Sollevare gambe a 90° per 10 min (riduce gonfiore)
```

### Protocollo recupero (24-72h)

| Tempo dopo dolore | Cosa fare |
|-------------------|-----------|
| 0-24h | Ghiaccio 3×15 min/giorno. Riposo cardio assoluto. Ok pesi upper body. |
| 24-48h | Cammino 20 min liscio (4-5 km/h). Niente corsa. |
| 48-72h | Test: cammino 10 min @ 6 km/h + 5 min jog 8 km/h. Se NO dolore → ok riprendere domani. |
| 72h+ | Riprendi piano gradualmente, riduci tutte le velocità di −1 km/h per 1 settimana. |

### Prevenzione long-term

- **Riscaldamento progressivo 5-8 min** (mai 2 min)
- **Pendenza tapis 1-2%** (riduce impatto)
- **Cadenza 160-170 ppm** (passi più corti)
- **Scarpe nuove ogni 600-800 km** o ogni 6 mesi se uso intenso
- **Stretching polpacci** (dopo workout, 2 min, no all'inizio)
- **Idratazione + pasto leggero pre-workout** se possibile

### Quando andare dal medico/fisio

- Dolore persistente >5 giorni nonostante riposo
- Dolore al tatto sul punto preciso (potrebbe essere stress fracture)
- Gonfiore visibile
- Dolore notturno o a riposo

## 🍽️ Alimentazione insufficiente nella giornata

### Sintomi
- Hai saltato pranzo o mangiato pochissimo
- Energia bassa, voglia bassa
- Glicemia probabilmente sotto

### Regola
**Se hai mangiato <60% del solito nelle ultime 8h prima del workout:**

| Workout pianificato | Modifica |
|---------------------|----------|
| HIIT | Cancella o sposta. Sostituisci con Z2 leggero 25 min. |
| Z2 lungo (45+) | Riduci a 30 min, velocità −1 km/h. |
| Z2 normale | OK ma riduci durata 25-30 min. |
| Pesi | Riduci serie a 2 invece di 3. Pesi −20%. |
| Recovery cammino | OK, va bene anche a stomaco vuoto. |

### Se devi proprio fare il workout:
- 30 min prima: 1 banana + 1 caffè
- Durante workout: piccoli sorsi acqua
- Subito dopo: pasto solido entro 30 min

## 😴 Stanchezza generale (sonno scarso, stress)

### Trigger
- Sonno <6h ultime 2 notti
- Energia check-in 1-2/5 ultimi 2 giorni
- RHR mattutino sopra 92 bpm (vs baseline 85)

### Regola

| Workout pianificato | Modifica |
|---------------------|----------|
| HIIT | Cancella. Sostituisci con Z2 25 min. |
| Z2 lungo | Mantieni ma riduci 10 min. |
| Z2 normale | OK come pianificato. |
| Pesi | OK ma RIR 3-4 invece di RIR 1-2. |
| Recovery | OK. |

### Quando saltare TUTTO
- Sonno <5h ULTIMA notte (singola notte cattiva): salta cardio intenso
- Sonno <6h ULTIME 3 notti: salta TUTTO. Riposo + dormi prima possibile.
- Influenza/febbre: ZERO allenamento finché >37°C scompare 24h.

## 🌡️ Riscaldamento — segnali precoci

Il riscaldamento è il TUO test diagnostico giornaliero.

| Sensazione durante warm-up | Decisione |
|----------------------------|-----------|
| Tutto fluido, energia ok | Procedi normalmente |
| Gambe pesanti ma cuore ok | Riduci velocità target di 1 km/h, procedi |
| Cuore alto a velocità basse | Probabile fatica/disidratazione. Riduci durata 30%. |
| Fastidio tibia/ginocchio/anca | STOP immediato. Cammino 5 min. Se non passa → recovery cammino e basta. |
| Vista offuscata, capogiri | STOP. Glicemia bassa o pressione. Riposo + cibo. |

**Regola d'oro:** se DURANTE il warm-up qualcosa non va, NON proseguire con la parte intensa "sperando passi". Quasi mai passa, peggiora.

## 🏃 Tapis vs Outdoor — differenze importanti

### Sul tapis
- Velocità è "data" (impostata): non tu detti il ritmo
- Superficie ammortizzata MA piatta = impatto ripetitivo identico
- No vento → BPM più alto a parità di sforzo (no raffreddamento)
- Niente cambi direzione → muscoli stabilizzatori meno attivi

### Outdoor
- Tu detti il ritmo (più adattivo)
- Superficie variabile = stress diversificato (meno overuse)
- Vento = raffreddamento naturale
- Cambi direzione attivi propriocezione

### Conseguenze pratiche
- **Velocità outdoor 11 km/h ≠ tapis 11 km/h**: outdoor sembra più facile
- **HRmax outdoor leggermente più basso** (vento)
- **Per Ariet vero (test):** prepara con shuttle reali, non solo tapis
- **Pendenza tapis 1-2%** simula approssimativamente outdoor

## 📊 RPE — Rating of Perceived Exertion

Scala 1-10 da usare nel check-in.

| RPE | Sensazione | Esempi |
|-----|-----------|--------|
| 1-2 | Molto facile | Cammino lento |
| 3 | Facile | Cammino veloce, parli senza problemi |
| 4 | Moderato | Jog leggero, conversazione comoda |
| 5 | Un po' impegnativo | Z2, frasi brevi |
| 6 | Impegnativo | Z3, conversazione difficile |
| 7 | Difficile | Soglia, parole singole |
| 8 | Molto difficile | Z4, respiro impegnato |
| 9 | Massimale | Z5, tutto |
| 10 | Impossibile sostenere | Sprint massimo |

**Target Alex:**
- Z2: RPE 4-5
- HIIT: RPE 6-7 medio, 8-9 nei picchi
- Recovery: RPE 2-3

**Allenamento del 5 mag = RPE 7 "Difficile":** appropriato per HIIT MA con dolore tibia → **rosso**, non verde.

## 🚦 Sistema semaforo decisionale

L'app deve calcolare ogni mattina un "semaforo" basato su questi input:

### 🟢 VERDE — Procedi con piano normale
Tutti questi sono veri:
- Sonno ultima notte ≥7h
- Energia check-in ieri ≥3/5
- Nessun dolore segnalato
- Pasto principale ieri completo
- RHR mattutino entro +5 bpm dalla baseline

### 🟡 GIALLO — Riduci intensità −20%
Almeno uno di questi:
- Sonno 6-7h
- Energia ieri 3/5
- Dolore lieve in zona muscolare (no articolare)
- Pasto principale ridotto

### 🔴 ROSSO — Recovery o salta
Almeno uno di questi:
- Sonno <6h
- Energia 1-2/5
- Dolore articolare/tendineo (tibia, ginocchio)
- Pasto saltato
- Febbre/malessere
- RHR +10 bpm sopra baseline

## 📱 Implementazione in app (V1.1+)

L'app deve:

1. **Calcolare semaforo automaticamente** ogni mattina basandosi su check-in di ieri
2. **Mostrarlo prominente** in tab "Oggi"
3. **Adattare il workout suggerito** in base al semaforo
4. **Chiedere conferma** prima di procedere se rosso/giallo
5. **Loggare modifiche** per analisi pattern (es. "stinchi sensibili dopo HIIT")

### Pseudocodice (v1.5)

```
function calcoloSemaforo(checkinIeri, weights, baseline, signals) {
  let punti = 0;

  if (checkinIeri.sleep === '<6') punti += 3;
  else if (checkinIeri.sleep === '6-7') punti += 1;

  if (checkinIeri.energy <= 2) punti += 3;
  else if (checkinIeri.energy === 3) punti += 1;

  if (checkinIeri.pain) punti += 4;
  if (checkinIeri.foodReduced) punti += 2;
  if (checkinIeri.illness) punti += 5;

  // V1.5: signals scientifici (Plews & Buchheit 2017, Foster 2001)
  if (signals.hrvDrop) punti += 3;       // HRV calo >7% baseline 7gg
  if (signals.rhrRise) punti += 2;       // RHR +5 bpm baseline 7gg
  if (signals.sessionLoad > 2000) punti += 2; // sRPE 7gg in AU

  if (punti >= 4) return 'rosso';
  if (punti >= 2) return 'giallo';
  if (!checkinIeri || !signals.checkinFresh) return 'grigio'; // in attesa
  return 'verde';
}
```

## 📊 Signals scientifici (V1.5)

L'app calcola signals oggettivi dagli ultimi dati Apple Health/Watch e li
combina con il check-in soggettivo. Vedi `docs/CONTEXT_SCIENCE.md` per i
riferimenti peer-reviewed.

### HRV (SDNN) — `Science.detectHRVDrop`
- Calo >7% vs rolling baseline 7gg → +3 punti semaforo, motivo "HRV calo X%"
- Soglia conservativa (Plews & Buchheit 2017 usano 7%).
- Dato proviene da Apple Watch (notturno automatico) via bulk import.

### RHR — `Science.detectRHRRise`
- Rise ≥5 bpm vs baseline 7gg → +2 punti semaforo
- Indica recupero incompleto o inizio illness.

### Session RPE — `Science.calcSessionLoad`
- AU = Σ (RPE × duration_min) ultimi 7gg.
- >2000 AU → banner "considera Z2 leggero al posto di intensità".
- Soglia conservativa per Alex; aggiustabile in futuro su base dati.

### Taper graduato — `Science.taperVolumeMultiplier`
- T-5..T0 dal test: durata workout × {0.9, 0.7, 0.5, 0.2, 0, 0}.
- Non sovrascrive il piano, modifica la durata e mostra modifier.

### Pain alternatives — `Science.alternativesForPain`
- Mapping zona dolore → alternative no-impact:
  - `tibia`: bici Z2, vogatore, nuoto, pesi upper
  - `ginocchio`: nuoto, pesi upper, mobilità
  - `schiena`: mobilità, nuoto dorso, cammino
  - `caviglia`: bici, pesi upper, nuoto
- Tap su alternativa → apre form workout pre-compilato (`prefillAltWorkout`).
